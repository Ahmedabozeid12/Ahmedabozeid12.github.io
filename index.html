Featured project

SOCRAT — Car Service Center System

A complete web application that runs the whole visit of a car — booking, job card, services, parts, car wash, invoice and payment — built with Oracle APEX 26 and PL/SQL. The web upgrade of my Oracle Forms system.

Live demo GitHub Documentation
👥

5 roles

Manager, Supervisor, Reception, Storekeeper and Customer — each with its own landing page and menu.

🔧

Job cards

Interactive Grid for services with a technician on each line, Faceted Search with live counts.

📦

Inventory

Goods receiving and parts issue, with stock kept correct by PL/SQL and a database trigger.

🧾

Invoicing

Maximum discount per role, 14% VAT, partial payments by Cash, Visa, InstaPay or Wallet.

📱

Customer portal

Sign up, add cars, book an available slot and cancel it — without calling the center.

🌓

Arabic UI

Full RTL interface, light and dark themes per user, Dynamic Actions and Ajax everywhere.

Database design

22 tables in five groups. A visit runs CUSTOMERS → VEHICLES → JOB_CARDS → INVOICES → PAYMENTS, with services, parts and the wash hanging off the job card.
